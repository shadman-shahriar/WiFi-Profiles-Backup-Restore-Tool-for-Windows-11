# WiFi Profiles Backup & Restore Tool for Windows 11

![Windows](https://img.shields.io/badge/Windows-11-blue?logo=windows)  ![Batch](https://img.shields.io/badge/Batch-Script-4D4D4D?logo=windows-terminal)  

A simple yet powerful batch script to **backup** all saved Wi‑Fi profiles (SSID + password) into a readable CSV file, and **restore** them later – ideal for Windows reinstallation, device migration, or system recovery.

> **Created by:** Shadman Shahriar

---

## ✨ Features

- ✅ **Backup** all saved Wi‑Fi networks (SSID, Authentication, Encryption, Password) to a `.csv` file  
- ✅ **Restore** Wi‑Fi profiles from a previously created CSV backup  
- ✅ **Readable CSV format** – passwords are stored in plain text for easy viewing/editing  
- ✅ **Custom backup location** – choose any folder (default is Desktop)  
- ✅ **Back to home** option on both backup and restore pages  
- ✅ **Automatic admin elevation** – script re‑runs with administrator privileges if needed  
- ✅ Works on **Windows 11** (also compatible with Windows 10, 8, 7)
